**API Gateway**

На входе система имеет **Kong Gateway**, выполняющий аутентификацию пользователей по JWT, лимитирует запросы и
маршрутизирует их в соответствующие сервисы.
Выбрал Kong из-за наличия готовых плагинов и высокой производительности на базе Nginx, не требующих специальных знаний
при настройке. 
Отсутствие потенциальных проблем в случае переписывания микросервисов на другие языки(в отличии от spring cloud  gateway)

## **Банк со следующим ландшафтом:**


* Мобильный банк / веб-банк для клиентов.

* Wallets – кошельки/счета клиента, баланс, блокировки.

* Payments – жизненный цикл платежа: создание, резервирование, списание, статусы, коллбэки мерчантам.

* Callbacks – уведомления внешних мерчантов и внутренних сервисов о статусе платежей.

* Core Banking (Legacy) – основной бухгалтерский учёт, менять мало и аккуратно.

* Anti-Fraud / Scoring – онлайн-проверки операций, скоринг риска.

* Notifications – SMS/push/email.

* Есть интеграции с внешними платёжными провайдерами (карточный процессинг, СБП и т.д.).
